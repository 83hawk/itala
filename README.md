📝 Itala (Simple Notes)
A minimalist, high-performance note-taking application written in Rust using the egui framework. Designed for simplicity and speed, Itala provides a distraction-free writing environment.
✨ Key Features

    Minimalist UI: A clean, dark-themed interface built for focus.
    Immediate-Mode GUI: Powered by egui for a highly responsive and lag-free user experience.
    Persistent Storage: Quickly save your notes to local storage with the dedicated "Save..." button.
    Memory Safe: Leverages Rust's ownership model to ensure a crash-free and secure environment.
    Native Performance: Compiled to native machine code for minimal CPU and RAM usage.

🛠️ Tech Stack

    Language: Rust
    GUI Framework: egui (Immediate-mode GUI library)
    Build Tool: Cargo
